# Pocket 3 in Argentina

An offline-capable field guide for a borrowed DJI Osmo Pocket 3.

Single self-contained page plus a service worker, so that once it has been
opened on Wi-Fi it keeps working with no signal. On iPhone: open in Safari,
Share > Add to Home Screen, then open it once more from the home screen.

- `index.html` — the whole guide: markup, styles, script and diagrams inline
- `sw.js` — caches the page for offline use
